<h2 align="center">站点概览</h2>

Site-█████-41是逆模因部与超形上学部共同设立的文档保存设施。Site-█████-41位于上层叙事，由超形上学部和SCP-██-████、███████提供叙事锚定，使存档文档的存在不依赖任何单一仓库或人员的记忆。其设立目的，是为那些带有逆模因危害的文档，提供一处独立于下层叙事运行机制的保存位置。

在下层叙事中，文档由于逆模因或认知危害等等特性而无法被安全的认知和观察。但是在这里进行对文档进行整理，可以不受到模因和逆模因危害。本文档中看似被删除的信息是手动删除而非异常删除。 该站点已存储少量带有逆模因效应的文档。

<h2 align="center">常驻部门</h2>

<p align="center"><img src="/%20%20%20%20%20/assets/departments/antimemetics-division.png" width="160" alt="逆模因部"></p>

<h3 align="center"><a href="https://scp-wiki-cn.wikidot.com/antimemetics-division-hub">逆模因部（Antimemetics Division）</a></h3>

**概述：** 逆模因是一种具有自我屏蔽特性的概念，能够阻止或防止他人的传播。逆模因部的目的在于研究与收容异常逆模因。这些概念，物件，以及实体会危及常态乃至人类生命，却又难以记录，甚至无法记忆。

经过仔细观察，深度训练，以及定期服用记忆强化药物，逆模因部得以处理其他人都忘掉的威胁。

<p align="center"><img src="/%20%20%20%20%20/assets/departments/pataphysics-department.png" width="160" alt="超形上学部"></p>

<h3 align="center"><a href="https://scp-wiki-cn.wikidot.com/departments#pataphysics-dept">超形上学部（Pataphysics Department）</a></h3>

**概述：** 超形上学部（或称“超形上学”）将假说物理学与文学分析学结合起来，研究某种现实本身成为虚构的情况。该部门驻扎在威斯康星斯洛斯皮特的 Site-87，负责收容叙事性异常，以及大量利用现实本质漏洞的宏大项目以实现基金会的使命。

尽管超形上学部与其收容的异常一样是虚构的，有一个引人入胜的故事也能让其拥有自己的生命。
